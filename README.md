# 🤖 Robotics & Mechatronics Projects Portfolio

## 📌 Repository Overview

This repository contains a collection of **robotics and mechatronics projects** developed through hands-on engineering work in **robot design, embedded systems, control systems, mechanical design, and AI-based robotics**.

# 📂 Projects Included

---

## 🧭 1. Line Follower Robot (Arduino)

An autonomous robot capable of following a predefined trajectory using **infrared sensors** and a **PD control algorithm**.

This project demonstrates sensor processing, feedback control, and real-time decision making for autonomous navigation.

**Technologies:**  
Arduino · IR Sensors · PD Control · PROTEUS · SOLIDWORKS

📁 Folder: `Line Follower Robot`

---

## 🚗 2. All-Terrain Robot (ESP32)

An all-terrain mobile robot based on an **ESP32 microcontroller**, controlled in real time using a **PS3 Bluetooth controller**.

The project focuses on wireless communication, motor control, and mechanical design for outdoor robotic mobility.

**Technologies:**  
ESP32 · Bluetooth · Motor Control · Embedded Systems · Robotics

📁 Folder: `All Terrain Robot`

---

## ⚔️ 3. Fighter Robot (STM32 / Hoverboard)

A combat-oriented robot based on an original **hoverboard motor controller using an STM32 microcontroller**.

The original firmware was modified and adapted to enable remote control operation and high-torque motor management.

**Technologies:**  
STM32 · Hoverboard Controller · RC Remote · Motor Control · Embedded Systems

📁 Folder: `Fighter Robot`

---

## 📷 4. Surveillance Robot (ESP32-CAM + AI)

A surveillance robot integrating embedded systems with computer vision.

The robot uses an **ESP32-CAM module** and **YOLO-based object detection** to provide real-time monitoring capabilities.

The project combines:

- Mobile robotic platform
- Wireless camera system
- Artificial intelligence
- Object detection

**Technologies:**  
ESP32-CAM · YOLO · Computer Vision · Arduino IDE · Mechanical Design

📁 Folder: `Surveillance Robot`

---

## 🦾 5. Stewart Platform - 6 DOF Parallel Robot

A **6 Degrees of Freedom (6-DOF) parallel robotic platform** designed, simulated, and implemented using six **Firgelli Filt0805 linear actuators**.

The project focuses on the design and validation of a robotic mechanism capable of performing controlled translations and rotations through coordinated actuator movements.

**Main Contributions:**

- Mechanical structure design
- Electrical architecture
- Actuator integration
- MATLAB simulation
- Robot kinematics analysis
- Prototype validation

**Technologies:**  
MATLAB · Parallel Robotics · Linear Actuators · Mechanical Design · Control Systems

📁 Folder: `Stewart Platform`
